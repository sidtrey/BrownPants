# Feature Review Checklist

Use these questions for every user-facing feature before calling it ready:

1. **Can agents use it?** Is there a documented, deterministic tool or host instruction, and are its limits clear?
2. **Can people use it?** Can a human find the feature, understand the result, and act on it without depending on an agent?
3. **Is it useful?** Which real task does it make easier, and what evidence shows that?
4. **Can it be meaningfully better?** Name a concrete improvement with user value and acceptance checks, or record why further work is not justified.

Record gaps as follow-up tasks or queue them in FIFO order. Do not call a feature complete based on implementation alone; test its entry point, review its user-facing output, and state any manual validation still needed.
