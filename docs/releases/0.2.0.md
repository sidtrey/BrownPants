# BrownPants 0.2.0

BrownPants 0.2.0 adds draft pull request submission for GitLab.com and Bitbucket Cloud to the existing evidence-backed local preview workflow.

## What changed

- Submit a reviewed preview as one GitLab.com draft merge request or Bitbucket Cloud draft pull request.
- Require explicit `--confirm` and `--online` flags, fixed provider API hosts, and provider-specific credentials.
- Preserve provider-independent offline previews and human-controlled review and merge.
- Add deterministic HTTP contract tests and packed-tool command-routing smoke checks.
- Keep all project and test dependencies unchanged.

Self-hosted GitLab and Bitbucket Data Center are not supported. See the [GitLab](../../integrations/gitlab/README.md) and [Bitbucket Cloud](../../integrations/bitbucket/README.md) setup guides.

## Verification

Release CI builds and tests on Windows, Ubuntu, and macOS, checks NuGet vulnerabilities, validates acceptance criteria and evidence ledgers, packs the .NET tool, and smoke-tests the packed CLI and provider gates. No live provider credentials are used by CI.
