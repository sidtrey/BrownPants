# BrownPants 0.2.1

BrownPants 0.2.1 corrects the CI changed-ledger scan for release tags. A new tag now checks Spec Kit task and evidence files changed by the tagged commit, while normal branch pushes, pull requests, first branch pushes, and root tags keep their defined comparison behavior.

This patch also carries forward the BrownPants 0.2.0 GitLab.com and Bitbucket Cloud draft PR adapters. The package has no new runtime dependencies.

## Verification

The release is built from a commit with green branch CI, then tag CI repeats the cross-platform build, xUnit suite, acceptance integrity checks, package audit, packed-tool smoke checks, and release artifact validation. No live provider credentials are used.
