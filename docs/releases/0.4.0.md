# BrownPants 0.4.0

BrownPants 0.4.0 expands offline brownfield inspection to useful JavaScript and TypeScript source evidence while preserving explicit limits and deterministic reports.

## Highlights

- Inspect `.js`, `.jsx`, `.mjs`, `.cjs`, `.ts`, `.tsx`, `.mts`, and `.cts` files for source-located declarations, imports, exports, and call candidates.
- Resolve supported relative imports, declared npm/pnpm workspaces, and in-root `tsconfig` path aliases. Reports distinguish syntax-resolved, ambiguous, and unresolved relationships.
- Keep existing JavaScript/TypeScript factory and dependency-injection candidates, and add the source evidence to JSON and Markdown without changing the inventory schema version.
- Refine chart routes against the completed graph for top-down and left-to-right layouts, reducing unrelated connector crossings while preserving declared edges and label checks.
- Add no runtime dependencies. Analysis is bounded, read-only, offline, and does not execute JavaScript, install packages, or type-check projects.

## Limits

JavaScript/TypeScript results come from bounded syntax recognizers, not a standards-complete parser or compiler. Syntax-resolved relationships do not establish type correctness, overload binding, conditional package export selection, runtime dispatch, or execution. See the [source evidence guide](../javascript-typescript-evidence.md) for the supported rules and report meanings.

## Install

Download `BrownPants.Cli.0.4.0.nupkg` from this GitHub release and install it from the directory containing the package:

```powershell
dotnet tool install --global --add-source ./release BrownPants.Cli --version 0.4.0
brownpants inspect .
```
