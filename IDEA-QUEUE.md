3. **Acceptance-criteria integrity — implemented in feature 021** — Keep acceptance criteria fixed and verifiable throughout a task so an LLM cannot quietly move the goalposts. 4. **Lazy-load relevant context — implemented in feature 024** — BrownPants now retrieves a user-selected canonical instruction section by source and anchor, with stable Markdown/JSON output, source and line identity, fenced-code-aware heading indexes, and path/encoding/size safety. Guidance is synchronized across README and Spec Kit surfaces. Hosts must invoke retrieval and may still preload every instruction file; BrownPants makes no token-savings guarantee.
5. **Why can’t LLMs lazy-load context? — research completed** — A model can only reason over content included in its request; agent hosts can search/index locally and add selected results on demand. Retrieved text still counts as model input. Prompt caching can reduce the price of repeated prefixes on supported APIs, but cached tokens remain processed input and count toward context/rate limits. Hosts differ: for example, Claude Code loads parent `CLAUDE.md` files at launch while nested rules can load on demand. BrownPants can provide deterministic section discovery/retrieval, provenance, and size/token estimates; the host must invoke it, and estimates must not be presented as provider usage. Sources: [VS Code context](https://code.visualstudio.com/docs/agents/concepts/context), [OpenAI prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching), [Claude Code memory](https://code.claude.com/docs/en/memory), [Claude prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching).

Local HTML workbenches let non-developers review Spec Kit features and OpenSpec changes and return notes without an AI-specific CLI or network service. The Cursor `/brownpants-context` command installer and fallback contract pass Windows and Linux fixture checks. **On hold for post-release manual verification:** activate the adapters in signed-in Cursor/Copilot/Claude GUI sessions; repository tests do not launch those hosts. Keep brownfield understanding primary and the user experience approachable.
