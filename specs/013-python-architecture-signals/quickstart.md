# Quickstart: Verify Python Factory and DI Signals

1. Run `dotnet build BrownPants.sln` and `dotnet test BrownPants.sln`.
2. Inspect the Python test fixture output in Markdown and JSON.
3. Confirm factory and DI candidates have the same path, line, category, and `Candidate` evidence in each format.
4. Confirm comment and single/triple-quoted string examples produce no candidates.
5. Confirm Python language coverage is `Lexical candidate patterns` and repeat output is byte-identical.
